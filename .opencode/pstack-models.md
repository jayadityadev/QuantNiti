# pstack model configuration (OpenCode Free Tier)

Per-role model overrides for pstack skills on OpenCode using free Zen/Console models.
Each pstack SKILL.md names its defaults; the values here adapt them to available free providers.
A value of `inherit` uses OpenCode's active session model.
